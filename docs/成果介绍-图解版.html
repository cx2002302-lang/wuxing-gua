01它是什么：压缩之前的一道闸

对称性压缩是成熟技术：几万个状态折成几百个，计算便宜两个量级。但它的前提——“这个对称性是真的”——通常只是直觉。wuxing-gua 只做一件事：压缩之前，把对称性逐条对账验真。

02灵魂实验「孪生审判」：一样，也分两种

TCP 协议里有一对双胞胎状态：结构一模一样，各自只有一条出路、通向同一个终点——但等的东西不同。合并它们＝宣布“收到 FIN”等于“收到 ACK”，协议即错。
这一问由外部复核用公开标准（RFC 9293 + networkx 第三方对照）逼出，现已成为工具核心特性，并做成了开源教学仓「对称法庭 Symmetry Court」：TCP / DHCP / IMAP 三个公开协议案卷，三方仲裁 11/11 全吻合。
